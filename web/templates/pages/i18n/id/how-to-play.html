Aturan & tips

Cara main Tap Timer

Aturannya cuma satu: hentikan jam tersembunyi sedekat mungkin dengan target waktu.

Dasar-dasarnya

  1. Pilih target waktu. 5.00 detik itu yang klasik.
  2. Ketuk sekali untuk mulai. Jamnya tetap berjalan, tapi kamu tidak bisa melihatnya.
  3. Ketuk lagi saat kamu rasa target waktunya sudah lewat.
  4. Waktu aslimu akan terungkap. Makin kecil selisihnya, makin bagus.

Mode game

Tantangan Target Web + Aplikasi

Tentukan target lalu gantian pakai satu HP. Tiap pemain main tanpa melihat jam, dan game mengurutkan semua pemain berdasarkan seberapa dekat waktunya. Main gratis di browser-mu.

Turnamen Aplikasi

Bagan pertandingan satu lawan satu dengan unggulan acak dan bye otomatis kalau jumlah pemainnya ganjil. Cocok untuk malam main game, kelas, dan acara kantor.

Tim Aplikasi

Bagi grup jadi beberapa tim. Skor tiap tim adalah rata-rata skor pemainnya, jadi setiap ketukan berarti.

Tips supaya makin dekat

  • Hitung per setengah detik. "Satu-dan-dua-dan…" memberimu dua kali lebih banyak patokan daripada "satu, dua…".
  • Pakai ketukan lagu. Lagu sekitar 120 BPM punya dua ketukan per detik. Ikuti iramanya dalam hati.
  • Santaikan jarimu. Waktu reaksimu ikut dihitung. Biarkan jempolmu siap tepat di atas layar.
  • Jangan buru-buru di awal. Kebanyakan orang telat mulai menghitung, lalu berhenti terlalu cepat untuk menebusnya.
